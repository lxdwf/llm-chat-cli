### 城市结论（重要修正）

**原计划**：主投广深，长沙保底
**修正后**：**长沙主投 + 广深同步投（双线）**

理由：
1. **竞争池不是一个量级**：广深是全国二本生的公海；长沙主要面对湖南本地高校，池子小得多。
2. **成本容错**：长沙两居室 1900（合租更低），深圳 5700。**第一份工作大概率起薪不高，长沙的低房租 = 巨大的试错空间。**
3. **地缘**：我在益阳，长沙 1 小时可达，**实习和生活成本几乎为零**。
4. **长沙有真岗位**：存储 / 云计算 / 网安赛道在长沙设了研发中心（杉岩、同有、深信服等），这条赛道正是逆势增长的，且大量用 Python。

> 广州作为第二选择：**岗位数是长沙 1.6 倍，扣租后收入和长沙持平**，比我原以为的更值得投。

### 修正 1：项目选题推倒重来 ❌→✅

**原计划（作废）**：个人待办 / 笔记 API 服务、外卖项目
**原因**：搜索结果明确指出这类是烂大街项目，「HR 一眼就能扔掉，不用浪费时间」。

**新标准（两条硬指标）**：
1. **重复度极低** —— 全网搜不到同款
2. **落地亮点够多** —— 有真实数据来源、能演示、讲得清「为什么这么设计」

**推荐选题方向（选一个）**：
- **A. AI 应用类（最推荐）**：RAG 问答 / 文档助手 —— 2026 最稀缺，且能直接对上 JD 里的「AI/LLM 经验」加分项
- **B. 本地真实数据类**：抓湖南本地公开数据（如招聘信息、房价、天气、公交）做聚合 + 可视化 + 定时推送 —— **真实数据来源本身就是差异化**
- **C. 垂直工具类**：解决我自己或身边人的一个具体痛点（如「城院课程/成绩/通知聚合提醒」）—— 面试官问「为什么做这个」时能答出真实动机

> 关键：小公司不看项目多花哨，**只看能不能落地、能不能干活、能不能解决实际问题**。

### 修正 2：实习从「可选」升级为「必选」

搜索反复出现同一句话：**「有项目、有实习的人，跟只有课堂作业的人，完全是两种待遇」**。
对二本 0 基础，**没有实习 ≈ 拿不到开发岗 offer**。

**行动**：2026 年 12 月后（第一阶段结束时）立刻开始找实习，**长沙本地优先，薪资可谈**（哪怕低薪/无薪）。
我在益阳，长沙实习的通勤与生活成本极低，这是天然优势。

### 修正 3：准备「降档预案」，不能只赌开发岗

多篇文章给出三档路径，**必须逐级降档、双线准备**：

| 档位 | 岗位 | 我的策略 |
| — | — | — |
| 第一档 | 前端 / 后端 / 测试 / 运维 | 主攻，但要有差异化项目 |
| **第二档** | **技术支持 / 实施工程师 / 售前 / AI 工具运维** | **技术对口、竞争小，二本最优退路** |
| 第三档 | 不限专业的运营、销售、职能岗 | 兜底，春招后期启用 |

**时间线红线**：
- **12 月底**海投仍无反馈 → 立刻启用第二档
- **3 月**仍无起色 → 春招果断兜底，**先就业再择业**

> 核心原则：**毕业前手握一份 offer，远比死守开发岗最终失业强。**
