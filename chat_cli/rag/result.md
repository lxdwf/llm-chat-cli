## 4. 为什么分段修好了，召回反而更差？

### 4.1 直接证据：正确块的关键词被截掉了

| 题 | 正确块 | Dify 给这个块存的关键词 | 结果 |
| --- | --- | --- | --- |
| Q1 | 岗位库1#1 卓望公司 | Java / Python / 岗位 / 15k / 届校 / 27 / 24 / 99.9 / 99 / 卓望 / AI | 关键词里有“卓望”，但“AI/岗位/城市”通用词把分数摊薄，top-5 仍没进 |
| Q2 | 岗位库1#2 联通湖北省分公司（英语四级） | JSON / FastGPT / Agent / Python / 岗位 / RESTful / Dify / LangChain / AI / 校招 | 不含“联通/湖北/英语”，top-5 都进不来 |
| Q5 | 技能清单#5 第一层·打地基 | dict / ### / list / 生成器 / 异常 / 自定义 / 12 / Python / 虚拟环境 / #### | 不含“第一层/打地基/技能”，top-3 进不来 |

### 4.2 三个结论

1. **空块不是唯一瓶颈。** 修掉空块后，single 从 2/5 变成 1/5：Q3 还在，Q5 反而丢了。原因是 500 字合并块把“第一层·打地基”标题稀释进 Python 语法正文，关键词表里只剩 `dict/list/生成器`。
2. **经济索引的本质是“词面匹配 + 每块 10 个关键词”。** 它不认同义、不认实体组合，也不会因为“卓望”是公司名就自动加权。Q2/Q5 的正确块连查询词都不在关键词表里，排不进来是必然。
3. **Dify 的倒排索引可以少于 K。** Q4 只返回 2 条，因为没有任何块同时命中“城市/优先/为什么”这些词；向量检索通常会凑满 K 条，倒排索引不会。

### 4.3 这对 D5 验收意味着什么

- **分段验收：通过。** 146 vs 133，+9.8%，0 空块，说明“纯文本 + `@@BLOCK@@` + 500/50”是 Dify 上可复现的切块方案。
- **召回验收：不通过。** single 1/5、multi 0/3、cross 1/2，低于手写 D4。瓶颈已经从“切块”转移到“经济索引的关键词截断”。
- **下一步不是继续调分段，而是换索引。** 高质量 `text-embedding-3-small`（Dify 已配）或 `BAAI/bge-m3`，用同一批 `.txt`、同一 13 题重跑；重点看 Q1/Q2/Q5/Q9 是否回来。高质量会消耗 embedding 额度，但召回测试本身不消耗消息额度。

## 5. gold 标注问题（D6 要修）

- **Q3**：gold 写“没有此信息”，但语料里市场调研#8 明确有“杉岩数据 / 长沙 / 9K–14K / 本科 / 2027届”。按 gold 字面应算 0/1，按语料事实算命中。
- **Q6**：gold 只列“联通武汉分公司”，但语料里 15 个岗位块提到 Dify（去掉 2 个非公司块和 1 个只写“优先”的卓望后是 12 家）。gold 太窄，导致 5 家全中也被判 0/1。
- **Q8**：gold 是空数组，无法计算 Recall；只能人工看 top-5 是否“可投”。
- **Q4**：gold 是一大段答案，不是可匹配的实体/短语；检索题不该用整段答案当 gold，应该拆成“长沙主投 + 广深同步投”这类关键短语。

## 7. Dify 省掉/挡住

**省掉的 3 件事：**

1. 文件上传与解析
2. 分段、向量化、建索引
3. 召回测试与引用展示

**挡住的 3 件事：**

1. 自定义切块（表格按行切、表头注入、来源头）
2. 自定义检索（余弦、k、来源权重/过滤）
3. 经济索引每块只留 10 个关键词，长块的实体/标题会被截掉；这是 Q1/Q2/Q5 的直接死因

## 8. D5 实测结论

1. **分段修复成功**：`.txt` 146 段 vs 手写 133 段，+9.8%，0 空块；`.md` 的 186 段/+39.8% 和 9 字来源头问题消失。
2. **召回没有跟着变好**：single 1/5（Q3），multi 0/3（Q6 0/1、Q7 1/6、Q8 gold 空），cross 1/2（Q10）。比 `.md` 轮的 single 2/5 还少 1 题。
3. **Q5 是典型回归**：`.md` 轮 Q5 排第 3 命中；`.txt` 轮 500 字合并块把“第一层·打地基”标题稀释，关键词表只剩 `dict/list/生成器`，直接掉出 top-3。
4. **经济索引的第二瓶颈是 10 关键词截断**：Q2 的联通湖北块不含“联通/湖北/英语”，Q5 的第一层块不含“第一层/打地基/技能”；Q1 虽然含“卓望”，但被通用词摊薄。
5. **倒排索引可以少于 K**：Q4 只返回 2 条，不是 Dify 坏了，是没有块命中查询词。
6. **out 正常**：Q11–Q13 各返回 5 条无关块；检索阶段本来就该返回，拒答要等生成阶段。
7. **下一步**：不要继续调分段；用同一批 `.txt` + 同一 13 题切高质量（`text-embedding-3-small` 或 `BAAI/bge-m3`）重跑，重点看 Q1/Q2/Q5/Q9。若高质量仍不行，再考虑混合检索 + rerank。
